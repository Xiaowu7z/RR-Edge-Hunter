A2候选来源

支持 TXT、CSV、TSV、JSON、Base64、长粘贴、CIDR 与 HTTPS 订阅。任意公网 IP 可作为受限候选；私网/本地/保留地址会被拒绝，只有通过 3 轮 TCP 与两次严格 Cloudflare 身份下载复测的地址才会输出。

流量提醒：先并发小流量快筛，再进行 1 秒 HTTPS 吞吐测试。均衡/亚洲狩猎达标早停；最大带宽与双栈会消耗更多时间和流量。

A3Argo 域名兼容复核（可选）

A4Cloudflare DNS 同步（可选）

只支持 Cloudflare API Token，不支持 Global API Key。Token 仅保留在本次运行内存并发给 Cloudflare API，不写入浏览器存储、历史、日志或导出。手动同步每次都需要二次确认。
